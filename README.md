# ✨ Spinner Words

Whimsical -ing words for the Claude Code spinner, in the spirit of "Canoodling…".

## Use it

- **Just this project:** the words live in `.claude/settings.json` and apply automatically here.
- **Everywhere:** run `./install.sh` (needs `jq`) to merge them into `~/.claude/settings.json`, then restart Claude Code.
- **Only your words:** change `"mode": "append"` to `"replace"`.

## For funsies

- `./spin.sh` pulls a random word from `words.txt` and spins it.
- Add your own to `words.txt` and `.claude/settings.json`. Rule of thumb: the sillier, the better.
